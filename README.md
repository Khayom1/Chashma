# Чашма

Бозии тез барои се забон: тоҷикӣ, русӣ ва англисӣ. Калима меояд — тарҷумаи дурустро пеш аз пур шудани чашма интихоб кун.

**Муаллиф:** Хайём Абдурахмонов

**Репозиторӣ:** `chashma`

## Chashma

Быстрая игра на трёх языках: таджикский, русский и английский. Появляется слово — выбери верный перевод, пока родник не переполнился.

**Автор:** Хайём Абдурахмонов

## Chashma

A fast game in three languages: Tajik, Russian, and English. A word appears — pick the right translation before the spring overflows.

**Author:** Хайём Абдурахмонов
